# Template Repository for GeoGirafe

[![GeoGirafe](https://geogirafe.org/wp-content/uploads/geogirafe-badge.svg)](https://geogirafe.org)

## About this repository

⚠️ **This project is not meant to be used with `git clone`.**

Instead, it is designed as an npm template for creating a GeoGirafe application.

If you simply clone this repository, the following files will not be included and will need to be created manually to complete the setup.:

- vite.config.js
- tsconfig.js
- index.html
- mobile.html

**DO NOT COMMIT ANY OHTER FILE THAT IS NOT MEANT TO BE CLONED ON A FRESH GEOGIRAFE PROJECT**

For instance, do not commit:

```
public/about.json
iframe.html
index.html
mobile.html
api.html
tsconfig.json
vite.config.js
package-lock.json
```
